A lightweight, agent-friendly CSS starter kit.

Home Elements Utility Layout Components

The Philosophy

This is a starting point (a seed), not a library to install and update.

This project provides 80% of what is needed to start a project in a flat set of CSS files with sensible defaults.

Starting projects from a known baseline helps provide consistency across projects and reduces the chance of cutting corners when moving quickly.

How to Use

For AI Agents 🤖

  1. Copy the css-base/ folder to your project root.
  2. Read css-base/AGENTS.md for context.
  3. Link index.css in your HTML.
  4. Modify the files directly.

For Humans 🧑‍💻

Download the latest release, drop the folder into your project, and start editing.

View the source code on GitHub.

Change the colors in themes.css, tweak the grid in layout.css, and build your own components on top.

Explore the System

  • Elements: Typography and form defaults.
  • Utility: Helper classes for spacing and visibility.
  • Layout: Primitive components for positioning (Grid, Stack, Sidebar).
  • Components: Composite UI widgets (Toasts, Modals, Cards).
