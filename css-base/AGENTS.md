# CSS Base - Agent Context

> **DO NOT EDIT THIS FILE**. This file is intended to provide context for AI agents working with this library.

## Goal

This library serves as the **Initial State** for new projects. It is NOT a dependency to be preserved. You are expected to:

1.  Copy the `css-base` folder into your project (e.g., to `src/styles/`).
2.  **Modify** the files directly to suit the specific project needs.
3.  **Diverge** from this base.

## Architecture

- **Flat Structure**: All CSS files live in the same directory.
- **Entry Point**: `index.css` imports all partials. Link only this file in HTML.
- **Native CSS**: Uses variables (`--var-name`) and `@import`. No preprocessor required.

## File Guide

Read the header comments in each file for specific API details.

- `index.css`: The manifest.
- `reset.css`: Normalizes browser defaults.
- `themes.css`: Defines Design Tokens (`--colors`, etc.). **Start customization here.**
- `elements.css`: Base HTML tag styles.
- `layout.css`: Composition primitives (`.grid`, `.stack`, `.sidebar`).
- `components.css`: complex UI widgets (`.modal`, `.toast`).
- `buttons.css`: Button styling logic.
- `utility.css`: Single-purpose helpers (`.hidden`, `.text-center`).

## Usage Instructions

1.  **Installation**: Copy this folder to your workspace.
2.  **Updates**: Do not try to update this library. It is a seed, not a package.
3.  **Customization**:
    - To change colors: Edit `themes.css`.
    - To change spacing: Edit `--gap` variables in `layout.css`.
    - To add components: Create new files and `@import` them in `index.css`.

## Common Tasks for Agents

- **"Change the primary color"**: Open `themes.css` and update `--light-primary-color` and `--dark-primary-color`.
- **"Make a card grid"**: Use `.grid` from `layout.css`.
- **"Fix layout spacing"**: Check `layout.css` variables (`--stack-space`) before adding custom CSS.
